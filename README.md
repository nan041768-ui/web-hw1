## 구현 항목 체크
1. CSS 변수: style.css 맨 위 :root에 색 5개 이상, 글꼴 2개(구글 폰트), 간격 1개. 글자색, 배경색, 테두리색은 모두 var()로 씁니다(그림자와 오버레이의 반투명 검정 rgba(0, 0, 0, ...)은 예외) [✓]
2. 섹션 2개: <section id="mine"> 내 인생 영화 5편, <section id="boxoffice"> 일별 박스오피스 TOP 5(기준일 표시). 섹션마다 <h2>, 카드 제목은 <h3>. [✓]
3. 카드 10장의 포스터: TMDB 포스터 w342, alt에 "제목 포스터". 포스터가 없는 영화는 대체 표지. [✓]
4. 박스오피스 배지: 순위 배지 .rank(왼쪽 위), 누적 관객 수(천 단위 콤마, "명"), 순위 변동 .up, .down, .new(::before로 ▲, ▼, NEW와 색). [✓]
5. 6주차 효과 유지: 평점 배지 .badge(오른쪽 위), :hover에서 0.3초 동안 8px 떠오르고 노란빛 그림자가 생김. [✓]
6. 보드 격자: display: grid, 폭 360px 1열, 768px 2열, 1280px 4열. 미디어 쿼리 2개(min-width: 600px, min-width: 1024px)가 각각 눈에 보이는 변화를 만듦. 360px에서 가로 스크롤 없음. [✓]
7. 헤더: flex로 제목 왼쪽, 내비 오른쪽. 내비 링크 3개(#mine, #boxoffice, detail.html). 본문 max-width: 1100px 가운데 정렬. [✓]
8. 히어로: backdrop_path의 w1280 배경 + 어두운 그라데이션 오버레이, 제목과 한 줄 소개. [✓]
9. 상세 페이지 detail.html: 내 인생 영화 1편. 600px 이상에서 2단 grid(왼쪽 포스터 w500, 오른쪽 <dl>에 제목, 원제, 개봉일, 평점, 줄거리 전문), 배경에 backdrop_path 오버레이, "보드로 돌아가기" 링크, 헤더와 푸터는 index.html과 같음. [✓]
10. 캡처 3장: w360.png, w768.png, w1280.png(디바이스 모드, 저장소 루트). [✓]
11. 푸터(두 쪽 모두): TMDB 고지 두 줄 + KOBIS 출처와 기준일. [✓]
12. 검증과 README: W3C 검증기에서 두 쪽 모두 Error 0, README는 아래 양식대로. [✓]


## 어려웠던 점 3가지와 해결
 html과 css 대부분이 어려웠던 것 같습니다. 다른 교재나 자료를 참고하기 보다는 실습 안내pdf 자료를 주로 참고했습니다. pdf 외에 다른 자료를 찾아보지는 않았습니다.

 따로 참고한 자료가 없기 때문에 실습을 진행하면서 새로 알게 된 점을 기록해봤습니다.



## 새로 알게 된 점
- commit 할때 변경내용 '메세지' 작성 후 '커밋 및 푸시'를 누르지 않아도 '커밋'을 눌러도 된다.
- css에서 root 변수 선언을 하려면 가장 상단에 코드를 작성해야 한다.
- <h1> 태그를 쓴 후에 바로 <h3> 태그를 사용할 수는 없다. 
  (<h1> 다음으로 <h2>, <h3>... 순서대로만 사용 가능)


## 생성형 AI 사용 내역
- 질문 요지 : 코드를 길게 작성하다보니, 세로 줄 맞춤이 뒤죽박죽이 됐다. 하나하나 다시 맞추려니까 시간이 너무 오래 걸려서 자동으로 줄맞춤 되는 기능/단축키는 없는지 물어봤다.
- 답변 요약 : Windows, Linux 경우 Shift + Alt + F, Mac에서는 Shift + Option + F 
- 채택 여부 : 채택

- 질문 요지 : commit 과정에서 오류창이 계속 떠서 오류창 캡쳐 화면을 같이 보내면서 질문을 했다. "git 레포지토리 업데이트 내역이랑 vs코드 업데이트 내역이랑 충돌난것같은데 해결방법 좀 알려줘"
- 답변 요약 : 충돌 해결 후 병합 완료하는 방법, 소스 제어 탭 이동 -> 충돌 파일 선택 -> 코드 선택 및 수정 -> 스테이징 및 커밋
- 채택 여부 : 채택.
